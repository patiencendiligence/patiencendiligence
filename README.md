# 안녕하세요, 박민지입니다 👋

프론트엔드 개발자로 일하며 UI/UX 기획과 구조 설계에 관심을 갖고, 최근에는 생성형 AI를 실무에 적용하는 일에 집중하고 있습니다.

## 지금 관심 있는 것
- LLM 기반 서비스의 프롬프트·응답 구조 설계
- 사용자 흐름을 데이터로 검증하고 개선하는 일
- AI 도구가 "쓸 수 있다"를 넘어 실제로 현업에 정착하기까지의 간극
